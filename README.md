# Adaptive Multilingual Smart Glove

## Project Overview
A sign-to-speech communication prototype designed to help
people with speech or hearing disabilities communicate more easily.

## Objectives
- Recognize predefined hand gestures.
- Convert recognized gestures into text.
- Speak the corresponding message in English, Hindi, and Marathi.
- Explore flex sensors and an IMU for future glove integration.

## Current Development Stage
Software prototype using webcam-based hand gesture recognition.

## Planned Technologies
- Python
- OpenCV
- MediaPipe
- Scikit-learn
- Text-to-speech

## Future Scope
Integrate flex sensors and an IMU with a microcontroller
to develop the physical smart glove.

## Project Status
Under development.
